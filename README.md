# 随机抽签器 · 双模式随机工具

一款基于 Python \+ Tkinter 开发的**可视化随机抽签小工具**，支持 **放回 / 不放回** 双随机模式、智能重抽机制，界面简洁、逻辑严谨，适用于日常随机抽签、随机点名、随机分配场景。

## ✨ 项目特点

- 双模式切换：

    - **放回模式（真随机）**：数字可重复抽取、无抽取上限，无限重抽触发数字

    - **不放回模式（伪随机）**：数字不重复消耗池，抽完自动重置，最多 10 次智能重抽

- 内置黑名单：自动跳过指定禁用数字 

- 触发重抽池：命中 “后门” 自动触发重抽逻辑

- 可视化剩余数量提示，实时展示抽取状态

- 一键重置数字池，操作简单

- 内置关于页面，展示开源协议与项目地址

- 原生 GUI 界面，跨平台可用、无广告、纯轻量

## 📌 重抽机制说明

1. **不放回模式**

    - 命中触发数字最多自动重抽 **10 次**

    - 触发数字**不消耗池子**，直至抽到正常数字或达到重抽上限

2. **放回模式**

    - 无限循环重抽

    - **只要命中触发数字就持续重抽**，保证最终结果一定是非触发数字

## 🛠 运行环境

- Python 3\.8\+

- 内置 Tkinter（Python 自带，无需额外安装依赖）

## 🚀 使用方法

### 1\. 源码运行

```bash
python random_draw.py
```

### 2\. Windows 打包方式（推荐无报毒方案）

#### 使用 Nuitka 编译为原生 EXE（大幅降低误报）

```bash
pip install nuitka
python -m nuitka --onefile --windows-disable-console random_draw.py
```

#### PyInstaller 普通打包

```bash
pyinstaller -w random_draw.py
```
